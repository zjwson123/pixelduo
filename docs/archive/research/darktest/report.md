# 黑暗测试报告（2026-08-11）

> 目的：用现有 eagent/cc-proxy 通道实测 gpt-image-2 与 doubao-seedream 的真实可用性、延迟与成本。
> 方法：调用 generate-image skill 脚本（modelverse / ark 网关）生成同款商品摄影 prompt，记录耗时与输出；gpt-image-2 medium 另做一次直连请求抓取 usage token。

## 1. 实测数据

| 测试项 | 模型/质量 | 尺寸 | 耗时 | 输出大小 | 实测成本（官方价） | 水印 |
|---|---|---|---|---|---|---|
| 1 | gpt-image-2 / high | 1024×1024 | **148.3s** | 940 KB | ≈$0.211（官方计算器） | 无 |
| 2 | gpt-image-2 / medium | 1024×1024 | **34.5s** | 880 KB | **$0.0528**（1756 输出 token × $30/M + 28 输入 token × $5/M） | 无 |
| 3 | doubao-seedream-5-0-260128（Seedream 5.0 Lite） | 1920×1920 | **15.5s** | 107 KB | ≈$0.035/张（约 ¥0.25；¥0.3–0.6 档为 5.0 Pro 型号） | **自带"AI生成"标识** |

## 2. 关键发现

### 2.1 延迟（影响 UX 与产品承诺）

- gpt-image-2 high 实测约 2.5 分钟，medium 约 35 秒，seedream 约 15 秒。
- 大纲原指标"p95 出图 < 60s"对 gpt-image-2 high 不成立 → 指标改为分模型：seedream < 30s / gpt medium < 60s / gpt high < 180s；默认档建议 seedream 或 gpt medium，high 作为 Premium 选项。
- 必须异步任务队列 + SSE/WebSocket 进度推送（架构已含，体验上更关键）。

### 2.2 成本（与官方价一致，可用于定价校准）

- gpt-image-2 medium 1024²：1756 输出 token → **$0.053/张**，与 OpenAI 官方计算器一致。
- gpt-image-2 high 1024²：官方价 **$0.211/张**（若按 24 积分/张 = $0.24 定价，毛利仅约 12%，偏薄 → 建议 high 定价 26–28 积分，或只对 1024² 以下开放 high）。
- seedream 1920²（Lite 档）：**≈$0.035/张**（约 ¥0.25）。按 6 积分 = $0.06 定价毛利约 42%（若后续升级 5.0 Pro，成本升至 ¥0.3–0.6，需上调积分）。
- 注：代理通道（ModelVerse/ark）实际账单可能含加价，最终成本以渠道账单为准；上线前用官方/渠道账单复核一次。

### 2.3 Seedream 自带"AI生成"水印（合规 vs 付费权益冲突）

- 火山方舟输出默认带 **"AI生成"标识**（国内《深度合成内容标识》要求，合规上其实是"应该保留"）。
- 影响：**付费"去水印"权益无法作用于 seedream 的内置标识**。产品方案二选一：
  a) 保留合规标识，付费权益改为"无平台附加水印"（把平台自己加的角标去掉）；海外 BytePlus 版本单独确认能否关闭内置标识；
  b) 国内版强制保留标识（合规最优），把"去水印"只作为海外版的付费权益。
- 待拍板：见大纲 §11。

## 4. 结论

- 双模型通道当前完全可用（无 401/网络问题），延迟数据健康（seedream 快、gpt 高清慢但可接受）。
- 定价校准方向：seedream（Lite）6 分合理；gpt medium 8 分合理；gpt high 建议 26–28 分或限制尺寸。
